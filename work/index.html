Production CareOps

專為高血壓患者、印尼籍照護看護（Pengasuh）與家庭成員打造的行動優先 (Mobile-First) 照護營運系統。整合無縫雙語介面、即時血壓趨勢、結構化用藥進度與資料庫層級存取安全。

核心技術棧 & 全棧架構 (Full-Stack Ecosystem)

  • 前端與建置 Ecosystem: React 18, TypeScript 5.6 (全型別覆蓋), Vite 6, Tailwind CSS v4 (CSS-first 現代樣式), Bun 1.3 執行環境。
  • 後端與資料庫 (Backend & DB): Supabase (PostgreSQL), Row Level Security (RLS) 資料庫層級安全限制, Google OAuth 2.0 雙重白名單驗證。
  • 照護 UI/UX 創新 (CareOps UX): iOS 原創 WheelPicker 雙向滾輪選擇器、台灣高血壓學會 722 原則雙次量測自動流轉與 1 分鐘休息計時器。
  • 雙語無障礙 (Bilingual i18n): 印尼文（看護主用）與繁體中文（家屬主用）對稱切換，徹底消除跨國照護溝通障礙與紀錄錯誤。

軟體工程原則 & 設計模式 (Engineering Principles & Patterns)

  • Defense in Depth (資安深層防禦): Google OAuth + DB 層級 Supabase RLS 雙重認證。未授權請求由 PostgreSQL 核心直接封鎖，落實零信任 (Zero Trust) 資安。
  • Single Source of Truth (SSOT 單一真實來源): 規範全專案 AI 協同憲法 (AGENTS.md)，搭配靜態型別與資料庫權限單一源頭，杜絕規則分歧。
  • Finite State Machine Pattern (有限狀態機): 封裝 722 量測流轉狀態 (IDLE → RESTING → SECOND_READY → COMPLETED)，精確控管 1 分鐘休息倒數與狀態變遷，防止非法連點。
  • Strategy Pattern & Value Object (策略模式): 抽象家庭血壓 722 警示演算法 (Normal / Warning / Danger) 與時段自動判定 (Pagi/Siang/Malam)，結合雙重視覺標示落實無障礙規範 (a11y)。
  • DevOps & Disposable Test Pipeline (拋棄式 CI/CD): 92.9%+ Vitest 單元測試涵蓋率、GitHub Actions PR 自動於拋棄式 Local Supabase 跑 DB Reset 重播 migration，搭配隔離的 Staging 驗收環境。
