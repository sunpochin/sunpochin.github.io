Family Health Log ｜ 家庭健康與照護營運系統

「媽媽今天吃的是新藥單，還是上週的舊藥單？」

專為高血壓患者、印尼籍照護看護（Pengasuh）與台灣家庭成員設計的雙語健康與用藥紀錄工具。解決長輩血壓紀錄零散、跨語言溝通障礙與藥物備忘遺漏等切身痛點。

🇮🇩 🇹🇼

中印雙語對照 UI & 無障礙介面

專為長輩與印尼看護優化大字體、高對比與直覺雙向切換，徹底消除跨國照護溝通障礙與紀錄錯誤。

🛡️

Supabase RLS 資料層存取防護

敏感個人健康數據不只在前端隱藏，更於 PostgreSQL 設定 Row Level Security (RLS) 白名單權限，確保未授權存取於資料庫層被拒絕。

🧪

雙端 Staging 驗收與 92.9% 測試

建立獨立 Vercel + Supabase Staging 環境，結合 GitHub Actions 拋棄式 Migration 驗證與 92.9%+ Vitest 單元測試，確保家人正式數據不受測試干擾。
